`muted` clears the 4.5:1 threshold by 0.01. It is fine as-is, but it is the
first thing to break if `paper` is ever lightened. Re-run before changing it:

```python
def lum(h):
    h = h.lstrip('#'); c = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    c = [x / 12.92 if x <= 0.03928 else ((x + 0.055) / 1.055) ** 2.4 for x in c]
    return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]
def cr(a, b):
    la, lb = lum(a), lum(b)
    return round((max(la, lb) + 0.05) / (min(la, lb) + 0.05), 2)
```

### For LLMs
- Design values belong in `theme.json`, not `style.css`. A hex written into
  `style.css` will not appear in the editor sidebar and will not follow the dark
  scheme, which keys off the `--wp--preset--color--*` custom properties.
- `settings.custom` keys are emitted as `--wp--custom--<key>--<subkey>`, and
  camelCase is converted to kebab-case. Keep the keys lowercase to avoid
  guessing at the generated name.
- Variable fonts declare a weight *range* (`"fontWeight": "400 600"`). Writing a
  single weight there makes the browser synthesize the others, which looks
  subtly wrong at heavier weights.
- The `display` size maxes at 7rem with a 3.25rem floor. Anything relying on the
  hero fitting on one line must be checked at both ends of that clamp.
