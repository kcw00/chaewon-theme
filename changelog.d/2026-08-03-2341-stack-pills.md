### For LLMs
- **The group is a `core/group` with `is-layout-flow`, and flow layout
  emits `margin-block-start` on every child but the first.** WordPress
  wraps that rule in `:where()`, so it has zero specificity and
  `.project__body .stack-group__items p { margin-block: 0 }` beats it.
  The chips would staircase without that declaration. This is the same
  footgun that has now bitten this theme five times; the running list is
  in section 02 of `style.css`.
- Chip text is authored, not derived. Adding a tool means editing the
  post body under Projects, not the `project_tech` taxonomy — the
  taxonomy still drives the card chips only.
- **Detail dropped from the prose that is not recoverable from the
  chips**, worth folding into `02 What it does` if it should survive:
  - minion — OTLP exporter uses proto-http rather than grpcio, on
    purpose, to keep multi-arch builds simple; and is inert unless
    `MINION_OTLP_ENDPOINT` is set
  - minion — multi-arch image (arm64 dev Mac, amd64 cluster) from a
    single `node:20-slim`, non-root; 131+ tests

    consumed by every service as a file dependency
  - booking — Postgres in prod with an SQLite fallback for bare local

  - pawbondai — hybrid semantic and structured filtering across six

  - discord-bot — `prometheus_client` Counter, Histogram, and Gauge
